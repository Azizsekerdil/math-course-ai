# Privacy

Math Course AI is a **single-user desktop program**. It has no server, no account, no
telemetry and no analytics. Nobody — including the maintainer — receives your data.

This document describes what the program stores on **your** machine, and the one path
by which data can leave it.

---

## 1. What is stored, and where

Everything lives under `%APPDATA%\MathCourseAI\`. Nothing is stored in the repository
and nothing is uploaded.

| Path | Contents | Personal data? |
|---|---|---|
| `data\student_tracker.sqlite` | learner name, questions, typed answers, correctness, timings, notes, exams | **Yes** |
| `data\language_dictionary.sqlite` | searched words, translations, PDF vocabulary, favourites | Possibly |
| `terminal_tutanak.jsonl` | AI Terminal work record — **full text** of your requests and the model's answers, the code that ran and its output | **Yes, if you typed something personal** |
| token ledger | per-request counters only: timestamp, provider, model, token counts, seconds, outcome | No |
| `<program>\settings\` | window layout and UI preferences | No |
| `<program>\exports\` | files you asked the program to produce | Whatever you exported |

The two ledgers are deliberately different and the program says so on screen:

- the **token ledger** stores counters and never request text;
- the **work record** stores the full text on purpose, so you can find the code you
  had the model write last week.

## 2. Children's data

If the learner is a child, the study database holds a child's name and performance
history. Under GDPR and KVKK that attracts heightened protection. The program never
transmits it, but:

- it is stored **unencrypted**, protected only by Windows file permissions;
- anyone with access to that Windows account can read it;
- if you back up `%APPDATA%\MathCourseAI` anywhere, you are copying that data.

Use a separate Windows account per learner if that matters in your setting.

## 3. What leaves your machine

Exactly one path, and only with an explicit per-session choice: the **optional cloud
AI provider**. See [AI_TRANSPARENCY.md](AI_TRANSPARENCY.md) for the complete field
list. In summary — your prompt and the last 12 conversation turns are sent; the study
database, the work record and the token ledger are **not**.

With the local model (the default) nothing leaves your machine at all.

There is **no** crash reporting, **no** update check, **no** usage analytics and
**no** advertising or tracking identifier anywhere in this program.

## 4. Your rights over your own data

Because there is no controller other than you, GDPR/KVKK rights are exercised
directly on the files:

| Right | How |
|---|---|
| Access / portability | The databases are plain SQLite; open them with any SQLite tool. The weekly report and CSV exports also work. |
| Rectification | Edit any question, attempt or note in the app. |
| **Erasure** | Deleting a learner removes their learner row, attempts, exams **and exam answers** — see below. Deleting `%APPDATA%\MathCourseAI` removes everything. |
| Restriction / objection | Do not use the feature; there is no processing you cannot stop by closing the program. |

### Erasure completeness

`StudentStore.delete_student()` deletes, in order: `exam_items` reachable through that
learner's exams, then `attempts`, `exams` and finally `students`. It returns the row
counts so the deletion can be verified.

This is a fix. Earlier versions deleted the learner, their attempts and their exams
but **not** `exam_items`, which has no `student_id` column — every typed exam answer,
correctness flag and timestamp was retained indefinitely with no path left to reach
it. Regression test: `test_ai_code_guard.py :: test_right_to_erasure`.

## 5. Demo data and screenshots

All demo content in this repository is **synthetic**, generated by
`tools/make_demo_resources.py`. The screenshots in `tanitim_gorseller/` were captured
against a fresh profile with no learner data — every counter reads zero and the
profile is the generic default. No real name, contact detail, address, phone number,
health or allergy information, guardian detail, payment information or location
appears anywhere in this repository, in any image, or in the presentation.

## 6. Third-party services

| Service | When contacted | What it receives |
|---|---|---|
| LM Studio (local) | when you use an AI feature with the default provider | your prompt — over loopback, on your own machine |
| NVIDIA NIM (cloud) | only after explicit per-session consent | your prompt and the last 12 turns |
| — | — | — |

Nothing else. The program contacts no analytics, no update server and no CDN.
