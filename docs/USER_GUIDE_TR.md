# Math Course AI — Kullanıcı Kılavuzu

Bağımlılıkları kurun ve yerel ortamı ana README dosyasındaki adımlara göre yapılandırın. Yalnızca işleme yetkiniz olan ders materyallerini kullanın.

1. Bir ders çalışma alanı ekleyin veya seçin.
2. Notlarınızı ve alıştırmalarınızı içe aktarın.
3. İstediğiniz analiz ya da çalışma akışını çalıştırın.
4. Üretilen içeriği paylaşmadan önce matematiksel doğruluğunu denetleyin.
5. Yalnızca yeniden dağıtma hakkınız olan içeriği dışa aktarın.
