Math Course AI - V45 Konu Bilgi Bankasi + Genisletilmis Kutuphane

EMBEDDED TOPIC KNOWLEDGE BASE (no AI required, ever)
- New module topic_knowledge.py: ~140 hand-written entries (272 normalised
  lookup keys, covering name variants) explaining core topics across every
  course - Prealgebra through Data Science.
- Every entry follows a fixed structure: an everyday analogy, "Nedir?"
  (definition, LaTeX where useful), "Ne Icin Kullanilir?" (2-4 numbered real-
  world/software/science applications), and - where a real discoverer exists -
  a "Tarih ve Biyografi" section with genuine, verifiable facts: who, roughly
  when, and why it mattered (Pythagoras ~570-495 BCE, Descartes 1637 Cartesian
  coordinates, Newton/Leibniz calculus 1665-1675, Gauss/Jordan elimination,
  Grassmann's 1844 dimension formula, Bayes 1763, Gosset/Guinness "Student"
  t-distribution 1908, and ~50 more). Purely procedural topics (rounding, unit
  price, order of operations) intentionally get NO fabricated history section -
  only genuinely attributable discoveries carry one.
- The ℹ topic window now checks this embedded base FIRST: instant, fully
  offline, zero AI calls. Verified against the real resource tree: 274 of 668
  distinct "Notes by section" topic names (41%) resolve immediately.
- Local LM Studio AI is no longer required or automatic - it is now an
  OPTIONAL manual fallback ("🤖 Yerel AI'dan Sor" / "🤖 Farklı Açıklama İste")
  for the topics not yet documented, or if you want a second opinion on a
  documented one. Previously AI-generated explanations remain cached and are
  still shown if present.
- Lookup is typo-tolerant: normalize_topic_key() strips accents, apostrophes,
  case, and separators, then falls back to a fuzzy (difflib) match - so
  "L'Hospital's Rule" and "l'hopitals rule" resolve to the same entry, but an
  unrelated made-up topic correctly returns nothing (no false positives).
- This is Round 1 of an ongoing, iterative build ("Doengue Muehendisligi" /
  loop engineering: generate -> evaluate coverage -> revise -> expand next
  round). Coverage will keep growing in future updates; topics not yet
  documented show a clear message instead of a fabricated answer.
