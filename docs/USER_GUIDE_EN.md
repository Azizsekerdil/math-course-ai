# Math Course AI — User Guide

Install the dependencies and configure the local environment as described in the main README. Use only course material that you are authorized to process.

1. Add or select a course workspace.
2. Import notes and exercises.
3. Run the requested analysis or study workflow.
4. Review generated material for mathematical accuracy before sharing it.
5. Export only content that you may redistribute.

The application has no administrator login surface, so the one-time `admin/admin` bootstrap rule is not applicable. Never place API keys in source files. The software is provided under the MIT License without warranty.
